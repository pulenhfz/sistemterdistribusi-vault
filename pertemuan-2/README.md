# Pertemuan 2 — Fungsi & Async

Dari function dasar sampai pola async/await, ditutup tiga tugas.

## Menjalankan

> Prasyarat: Node.js ≥ 18. Tidak ada dependensi eksternal.

Masuk ke folder:

```bash
cd pertemuan-2
```

Jalankan salah satu file:

```bash
node 01_function_dasar.js
node 02_arrow_function.js
node 03_callback.js
node 04_async_callback.js
node 05_async_await_readline.js
node tugas1.js
node tugas2.js
node tugas3.js
```

File yang meminta input akan menampilkan prompt di terminal.

## Daftar File

| File | Materi |
| --- | --- |
| `01_function_dasar.js` | function declaration |
| `02_arrow_function.js` | arrow function |
| `03_callback.js` | pola callback |
| `04_async_callback.js` | async + callback |
| `05_async_await_readline.js` | async/await dengan readline |
| `tugas1.js` | konversi suhu (C↔F) |
| `tugas2.js` | simulasi autentikasi asinkron (Promise) |
| `tugas3.js` | CLI kasir produk asinkron |
