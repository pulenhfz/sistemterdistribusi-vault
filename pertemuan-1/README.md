# Pertemuan 1 — Dasar JavaScript & Node.js

Materi pengenalan sintaks JavaScript di runtime Node.js: input/output konsol, percabangan, perulangan, dan tiga latihan mandiri.

## Menjalankan

> Prasyarat: Node.js ≥ 18. Tidak ada dependensi eksternal.

Masuk ke folder:

```bash
cd pertemuan-1
```

Jalankan salah satu file:

```bash
node hello.js
node input_output.js
node percabangan.js
node perulangan.js
node latihan1_kalkulator.js
node latihan2_kasir.js
node latihan3_prima.js
node latihan.js
```

File yang meminta input akan menampilkan prompt di terminal — jawab sesuai yang diminta.

## Daftar File

| File | Materi |
| --- | --- |
| `hello.js` | Hello world pertama |
| `input_output.js` | Input/output konsol |
| `percabangan.js` | `if/else`, switch |
| `perulangan.js` | `for`, `while`, `do-while` |
| `latihan1_kalkulator.js` | operasi aritmatika |
| `latihan2_kasir.js` | logika kasir sederhana |
| `latihan3_prima.js` | cek bilangan prima |
| `latihan.js` | latihan gabungan |
